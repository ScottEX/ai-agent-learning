## 每周怎么记录

1. 在 Notion 打开周任务，查看指定资料、学习目标和闭卷考题。
2. 把代码放进本周的 `exercises/` 和 `project/`。持续迭代的项目可在周目录记录本周对应的提交或标签。
3. 在 `tests/README.md` 记录运行命令、结果和证据，再填写 `ASSESSMENT.md` 和 `RETROSPECTIVE.md`。
4. 验收后同步 [PROGRESS.md](PROGRESS.md) 和 Notion 的实际成绩及状态。Notion 的「项目成果」字段可直达本周 GitHub 目录。

每周通过条件为总分至少 80、独立编码至少 24/30，且核心测试、独立变更和独立讲解均通过。
